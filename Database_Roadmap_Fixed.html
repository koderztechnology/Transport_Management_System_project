Database Roadmap - Complete System

System Overview: How Many Tables & Columns?

There are exactly 8 core tables in the entire Transport Management System. Here is their breakdown:

  • 1. CUSTOMERS Table — (6 Columns)
  • 2. VEHICLES Table — (6 Columns)
  • 3. DRIVERS Table — (5 Columns)
  • 4. USERS / STAFF Table — (5 Columns)
  • 5. INVOICES & PAYMENTS Table — (6 Columns)
  • 6. TRACKING Table — (7 Columns)
  • 7. LR_BILTY Table — (17 Columns)
  • 8. EWAY_BILL Table — (17 Columns)

* Below you will find the exact structure for every table, followed by Sample Rows showing you exactly what the actual data looks like inside the database!

1. CUSTOMERS TABLE (Consignors & Consignees)

Purpose: Stores all senders, receivers, and billing entities. Connects to LrBilty.

Structure (Columns)

Column NameData TypeConstraintNull Rules & Details
CustomerID (PK)INTNOT NULLAuto-increment unique ID. Mandatory.
CustomerTypeVARCHAR(20)NOT NULLConsignor, Consignee, or Broker.
FullNameVARCHAR(100)NOT NULLRegistered Name.
GSTINVARCHAR(15)NULL ALLOWEDLeave empty for B2C clients. Fill for B2B.
ContactPhoneVARCHAR(15)NOT NULLPrimary contact.
AddressTEXTNOT NULLComplete physical address.

7. LR_BILTY TABLE (Contract Core)

Purpose: The central pillar. This is the Lorry Receipt tracking the active transport job.

Structure (Columns)

Column NameData TypeConstraintNull Rules & Details
LrNumber (PK)VARCHAR(30)NOT NULLManual/Auto ID (e.g., LR-1050). Mandatory.
LrDateDATENOT NULLDate receipt generated.
ConsignorID (FK)INTNOT NULLSender ID from Customers.
ConsigneeID (FK)INTNOT NULLReceiver ID from Customers.
OriginVARCHAR(100)NOT NULLStart location.
DestinationVARCHAR(100)NOT NULLEnd location.
MaterialDescVARCHAR(500)NOT NULLGoods details.
TotalWeightDECIMAL(10,2)NOT NULLPackage weight.
TotalPackagesINTNOT NULLCount of boxes.
FreightAmountDECIMAL(10,2)NOT NULLTotal transport fare.
AdvanceAmtDECIMAL(10,2)NULL ALLOWEDPre-paid amount. EMPTY if 0 advance.
BalanceAmtDECIMAL(10,2)NULL ALLOWEDPending amount. EMPTY if 0 balance.
VehicleID (FK)INTNULL ALLOWEDEMPTY if truck is missing.
DriverID (FK)INTNULL ALLOWEDEMPTY if driver is missing.
EWayBillNoVARCHAR(20)NULL ALLOWEDEMPTY until Govt Bill generated.
DeliveryDateDATETIMENULL ALLOWEDEMPTY while tracking.
StatusVARCHAR(30)NOT NULLOverall Status (In Transit, Delivered).

8. EWAY_BILL TABLE (Govt Link)

Purpose: Mandatory government data link mapping taxes. Connects tightly to LrBilty.

Structure (Columns)

Column NameData TypeConstraintNull Rules & Details
EWayBillNo(PK)VARCHAR(20)NOT NULLOfficial govt generated number.
EWayBillDateDATETIMENOT NULLDate and time generated.
LrNumber (FK)VARCHAR(30)NOT NULLConnects to LrBilty.
GenByGSTINVARCHAR(15)NOT NULLGST number of the generator.
SupplierGSTINVARCHAR(15)NOT NULLGST number of the sender.
RecipientGSTINVARCHAR(15)NOT NULLGST number of the receiver.
DispatchFromVARCHAR(200)NOT NULLPincode / address it left from.
ShipToVARCHAR(200)NOT NULLPincode / address it's going to.
DistanceINTNOT NULLRequired transit distance (KM).
TotalInvoiceValDECIMAL(10,2)NOT NULLTotal monetary value of cargo.
CustomDutyValDECIMAL(10,2)NULL ALLOWEDEMPTY if not cross-border shipping.
CGSTAmountDECIMAL(10,2)NULL ALLOWEDEMPTY/0 if tax exempt.
SGSTAmountDECIMAL(10,2)NULL ALLOWEDEMPTY/0 if tax exempt.
IGSTAmountDECIMAL(10,2)NULL ALLOWEDEMPTY/0 if tax exempt.
VehicleNumberVARCHAR(20)NOT NULLReg number recorded per govt filing.
TransporterIDVARCHAR(50)NULL ALLOWEDEMPTY if internal fleet transport.
ValidUptoDATETIMENOT NULLGovernment expiration point.
